# Bundled assets

Commissioner, Literata and Rando Sans are bundled under the SIL Open Font License 1.1. Their notices are alongside the font files. Commissioner supplies interface text, Literata supplies titles, and Rando Sans supplies the footer caption.

The toolbar drawings, footer and full product badge are the accepted artwork from the Castor identity masters. The footer CSS and markup retain their master geometry. The product mark combines the existing search drawing with the unchanged full badge. No third-party photo or generated image is bundled. Apache 2.0 does not grant trademark rights.

The README title is generated from Literata outlines; its font notice is included in docs. The adaptive README footer is an exact master copy.
